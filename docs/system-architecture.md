# RevSignal product requirements

## Problem

Sales teams need a clear view of risky opportunities, why they are risky, and which action should happen next.

## MVP scope

The first MVP includes a CSV import workflow, explainable scoring rules, deterministic recommendations, and a dashboard that aggregates real imported deal data.

## Non-goals for this phase

- live CRM synchronization
- paid model APIs
- autonomous external actions
- algorithmic predictions trained on historical close data
