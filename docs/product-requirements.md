# RevSignal product requirements

## Problem

Sales teams struggle to identify which deals are at risk, why they are risky, and what action they should take next.

## MVP scope

This version includes the core flow:

- CRM CSV upload
- field normalization and validation
- explainable risk scoring
- next-best action recommendations
- dashboard metrics

## Non-goals

- live CRM sync
- paid API integrations
- automatic external actions
- model accuracy claims without historical outcomes
